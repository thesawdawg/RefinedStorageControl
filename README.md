# Refined Storage Control

A planned storage-network mod for 7 Days to Die 3.3.0 b18, inspired by Minecraft's Simple Storage Network, Refined Storage, and expanded crafter progression.

Centralized storage access is the primary goal. v1 includes wired physical storage, powered digital disks, and manual terminal crafting through native stations. Pattern automation and tiered crafters are planned for v2.
