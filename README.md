# Refined Storage Control

A planned storage-network mod for 7 Days to Die 3.3.0 b18, inspired by Minecraft's Simple Storage Network, Refined Storage, and expanded crafter progression.

Centralized storage access is the primary goal. v1 includes wired physical storage, powered digital disks, and manual terminal crafting through native stations. Pattern automation and tiered crafters are planned for v2.

## Planning documents

- [Current design, decisions, TODOs, and acceptance criteria](RefinedStorage-Design.md) — requirements source of truth.
- [Original research and integration draft](RefinedStorage-Research.md) — historical research; superseded design recommendations are identified at the top.
- [Answered discovery questionnaire](RefinedStorage-Questions.md) — original question numbering retained for reference.

Status: planning and local API inspection only. No loadable mod or gameplay implementation exists yet. Intended for Windows PC solo and player-hosted co-op, with up to six players and EAC disabled.
