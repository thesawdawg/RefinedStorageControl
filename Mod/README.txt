Refined Storage Control - 7 Days to Die 3.3.0 b18
=================================================

A wired storage network: reach every connected container and storage disk
from one terminal, and craft at connected workbenches, forges and campfires.

INSTALL
- Start the game without EasyAntiCheat (EAC must be off).
- Copy this RefinedStorageControl folder into <7 Days To Die>/Mods/.
- In co-op, the host and every player need the same version.
- New worlds are recommended.

SETTINGS
- Settings.xml in this folder: transfer rates, disk survival chance,
  crafting countdown, and more. Each entry explains its range. Restart the
  game after changing it. In co-op the host's file decides.
- F1 console: "rsc settings" shows the values in use.

YOUR DATA
- Saved next to the world: <save folder>/RefinedStorageControl/
  (disks.dat, nodes.dat, jobs.dat, journal.log). Back up the whole save
  folder with the game closed.
- "rsc disk export <id|all>" writes a readable list of a disk's contents.
- "rsc journal" shows recent transfers, disk and crafting events.

UPDATE
- Keep a copy of Settings.xml if you changed it, replace this folder, then
  put your Settings.xml back.

UNINSTALL
- Everything stored on DISKS IS LOST when the mod is removed. Move items
  into ordinary containers first, then delete this folder.
